# Networking Fundamentals

## Overview

Networking is the foundation of cybersecurity.

Every security professional needs to understand how devices communicate.

It is also important to know how data travels across networks and how common network protocols work.

## Learning Objectives

- Understand the basics of computer networking.
- Learn the OSI and TCP/IP models.
- Understand IP addressing (IPv4 & IPv6).
- Learn common network protocols.
- Identify the functions of network devices.
- Build a strong networking foundation for cybersecurity.

## Topics Covered

- OSI Model
- TCP/IP Model
- IPv4 & IPv6
- Public vs Private IP
- Subnetting
- DNS
- DHCP
- HTTP & HTTPS
- TCP vs UDP
- Router
- Switch
- Firewall
- VPN
